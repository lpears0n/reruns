Mic audio in every clip, new sounds, and less memory used in the tray.

## Everyone

- **Mic and game audio in one track.** With the mic on, clips mix the game and the mic into the first audio track, so both play in any player and in Discord. Before, the mic was on a second track that most players skip. Clips saved before this update keep the mic on track two: render one in the editor, or pick the second track in VLC under Audio → Audio Track.
- **New sounds.** A chime when a clip saves, a shutter for screenshots, and a lower chime when a save fails. They play as you press the key. A custom sound that won't play falls back to the built-in one on Windows; on Linux it stays silent.
- **Updates wait for your game.** A downloaded update installs after the game you're recording closes, and after any edit that is still rendering finishes. Downloads can be cancelled, and give up after 15 minutes. If you press Update while an edit is rendering, Reruns refuses; press it again once the render is done.
- After an update, Reruns opens its window and shows "Updated to" the new version.
- The update prompt shows the release notes. **Skip this version** hides that release. **Later** holds until the next launch.

## Windows

- **In-game popup.** Restyled, and shown only over the game you're recording: "Recording <game>" with your clip key, then "Last 30 s · <game>" after a save. It no longer appears over a launcher in front of the game.
- **Fewer repeated frames.** While recording, Reruns asks Windows for finer timer ticks, so the capture doesn't send the same frame twice. In a desktop capture test the rate went from 67 fps with 42 repeated frames to 60 fps with none.
- **Less memory in the tray.** The main window is built when you open it, and freed a minute after it's hidden or as soon as a game starts recording. On one PC the tray went from about 416 MB to about 50 MB.
- **Faster startup.** Encoders are no longer tested on every launch. The check runs when you open Settings.
- **Cancelled exports** clean up their unfinished file, so cancelling is quicker. If another program holds that file open, Reruns retries for about five seconds. If it's still locked, the file stays and the log says so; delete it once that program closes.
- **Smaller install.** Only the GStreamer libraries Reruns uses are bundled, and GStreamer is pinned to 1.26.9.
- The local clip server uses a random token on Windows; before, the token was predictable. It listens only on this PC.

Bugs: [open an issue](https://github.com/lpears0n/reruns/issues) with your log (Settings → General → Troubleshooting → Logs).
