Your mic in every clip, new sounds, and a much lighter Reruns in the tray.

## Everyone

- **Mic and game audio together:** with the mic on, clips start with game and mic mixed into one track, so you hear both in any player, in Discord and in Reruns. Before, the mic was on a second track that players skip, so it seemed to be missing.
- The editor still sets the game and mic levels separately for an edit.
- Clips saved before this update keep the mic on its own track. To hear it, render the clip in Reruns' editor, or pick the second audio track in a player like VLC (Audio → Audio Track).
- **New sounds:** a soft two-note chime when a clip saves, a shutter click for screenshots (they no longer share the clip sound), and a lower chime if a save fails. They play as you press the key. A custom sound that can't be played now falls back to the built-in one instead of making no sound.
- **In-game popup:** restyled, and shown only over the game you're recording. It says "Recording <game>" with your clip key, and "Last 30 s · <game>" after a save.
- **Updates don't interrupt a recording:** a downloaded update waits until the game closes, and until any edit or render finishes. The download has a time limit and a Cancel button, and a failed install is reported.
- After an update, Reruns opens its window again and says "Updated to" the new version.
- The update prompt shows the release's notes, and **Skip this version** stops it asking for that release. "Later" lasts until the next launch.

## Windows

- **Repeated frames in clips:** while it records, Reruns asks Windows for finer timer ticks and stops Windows slowing it down in the background. Without this, the capture could send the same picture twice. In a test capture of the desktop, the rate was 67 fps with 42 repeated grabs; with the fix it was 60 fps with none.
- **Lighter in the tray:** the main window is built only when you open it, and is freed a minute after it's hidden or as soon as a game starts recording. Measured on one PC: about 50 MB in the tray instead of about 416 MB, and a tray launch starts at about 40 MB.
- **Faster startup:** Reruns no longer tests every encoder each time it starts. That check runs when you open Settings.
- **Exports:** a cancelled or failed export removes its unfinished file in one place, so cancelling is quicker. On Windows, an unfinished file that another program has open is removed once that program lets go.
- **Smaller bundle:** the Windows install carries only the GStreamer parts Reruns loads, and is pinned to GStreamer 1.26.9.
- The local server that plays clips uses a random token on Windows; it was predictable before. It only listens on this PC.
