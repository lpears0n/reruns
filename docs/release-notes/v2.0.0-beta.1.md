A redesigned Reruns, and on Windows its own installer. This is a beta of 2.0.0: install it by hand, since copies on 1.2.0 won't offer it as an update. When 2.0.0 is published, the beta updates to it like any other release.

## Before you install

- **Back up first.** Nobody has checked yet that a 1.x library comes through the upgrade intact. Copy `%APPDATA%\reruns` on Windows, or `~/.config/reruns` and `~/.local/share/reruns` on Linux. Titles, favourites, tags and markers are in the `.json` file next to each clip, so they stay in your clips folder.
- The library's grouping choice (View → Group) resets once.
- **Windows:** Setup and the installer aren't code-signed, so SmartScreen says "Windows protected your PC". Choose More info → Run anyway.
- **Linux:** the new interface hasn't been run on Linux (WebKitGTK) yet. Expect layout problems, and please report them.

## Everyone

- **New look.** A dark sidebar with All clips, Favorites and a page for each game, plus a compact header with search and View. Settings opens over the library, so your search and scroll position are still there when you go back.
- **Library grouping.** Clips are grouped as Today, Yesterday, Past week, then by month. View → Group still offers By day, and a game's page can group its clips by play session. Each card's caption fits on one line, and the full details are in its tooltip.
- **Clip workspace.** An open clip shows one timeline of frames over its waveform. The trim handles show their time when you touch them. Copy clip changes to "Copied" once the file is on the clipboard.
- **Save clip** is one button with the game under it, and its ⋯ holds the options, including "*Game* is not a game". With no game running, a single line takes its place.
- **Keyboard.** `Ctrl+Z` undoes a delete. With a card focused, `F` stars it, `Ctrl+C` copies it and `Delete` deletes it. `/` goes to search.
- **Delete takes one click**, with six seconds to undo it. Several deletes in a row share one Undo. "Not a game" can be undone from its notice too.
- **Screenshots** appear among their game's clips. Open one full-window, or copy it, show it in its folder, delete it (with Undo) or drag it out.
- **Themes.** Settings → Appearance → Theme picks the accent: Off-white (the default), Blue, Mint, Violet, Pink or Rainbow.
- The update prompt keeps the keyboard to itself: Escape closes only the prompt. Settings → Check now opens the same prompt, with the release notes and Cancel.
- A setting that fails to save now shows the error.
- In an edit with slow motion, the cover and markers now land on the right frame.
- Try again after a failed copy now copies the file it already prepared. If the Sharing size limit has changed since, it prepares the clip again first.

## Windows

- **Reruns Setup.** Download `Reruns-Setup-2.0.0-beta.1.exe`: one window with Install, Update or Reinstall, and real progress. It installs to the same per-user folder as before (`%LOCALAPPDATA%\Reruns`). On a PC without WebView2 it hands over to the classic installer, which downloads WebView2. The classic installer now carries the Reruns mark too.
- **AV1 at high bitrates saves again.** AV1 replays that NVENC encoded at high tier (for example 3440×1440 at 120 fps and 50 Mb/s) failed to save with "not-negotiated".
- **Audio devices that change id.** When Windows gives a device a new id, as SteelSeries Sonar does with its Stream output, Reruns finds the device by its name. Before, it recorded the default output instead.
- **HDR white level.** When Windows doesn't report the display's SDR white level, Reruns asks again on every scan and restarts HDR window capture once the real value arrives. Before, it logged a guess of 80 nits as if Windows had reported it.
- **Known problem:** clips recorded with HDR compatibility can repeat or skip frames. Deadlock clips (AV1, 120 fps) had 0.9–13% repeated or skipped frames in one test.

Bugs: [open an issue](https://github.com/lpears0n/reruns/issues) with your log (Settings → General → Troubleshooting → Logs).
